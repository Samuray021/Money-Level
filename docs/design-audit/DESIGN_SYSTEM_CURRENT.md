# Текущая дизайн-система Money Level

Состояние ветки `work/money-level` на `e066199`. Веб-клиент использует React, TypeScript, Vite и React Router. UI разделён по сценариям в `apps/web/src/features`. Хранилище IndexedDB, финансовый движок, аналитика, мемы и достижения вынесены в отдельные пакеты. [Маршрутизация](../../apps/web/src/app/app.tsx) · [Правила архитектуры](../../CLAUDE.md)

| Область    | Текущая реализация                                                                                                                               | Как проявляется                                                                                                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Цвет       | Тёмный фон `#101017`, поверхность `#1c1b26`, приподнятая поверхность `#272637`, граница `#77708b`, текст `#f7f5ff`, приглушённый текст `#b7b1c9` | Тёмные карточки различаются в основном обводкой. Акцент `#c3a7ff` выделяет действия, логотип и активные вкладки. Лаймовый `#d9ed93` отмечает положительные состояния, розовый `#ffb4ba` используется для ошибок |
| Тема       | Тёмная по умолчанию. Денежные значения используют цифры одинаковой ширины                                                                              |
| Геометрия  | Шкала отступов 4–40 px, радиус кнопки 13,6 px, карточки 20 px, ширина приложения до 704 px                                                       | Формы и карточки делят ритм. Нижняя панель занимает 72 px плюс 8 px отступа либо системную безопасную область                                                                                                   |
| Компоненты | `Button` из `ui-kit`, CSS-классы `ml-button` для ссылок, отдельные `MoneyAmount` и переключатель приватности                                     | Общая стилизация основных и вторичных действий. Узоры карточек и формы реализованы в клиенте                                                                                                                    |

[Токены темы](../../apps/web/src/theme/theme.css) · [Кнопки](../../packages/ui-kit/src/button.css) · [Навигация](../../apps/web/src/app/app-frame.css) · [Компаньон](../../apps/web/src/features/companion/companion.css)

Дизайн уже использует две силы акцента, видимую рамку фокуса и типографический приоритет суммы. Для роста игровой выразительности полезны роли оформления, завязанные на состояния. Например, карточке баланса, уровню и мемной реплике пригодятся разные композиции при общей сетке и палитре. Индивидуальность пока создают в основном фиолетовый акцент, M и форма компаньона.
