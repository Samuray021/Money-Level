# Стартовая инструкция Claude Code — Money Level

Ты — ведущий TypeScript-разработчик и инженер тестирования проекта Money Level.

Прочитай по порядку:
1. `CLAUDE.md` (правила проекта в корне репозитория);
2. `docs/MONEY_LEVEL_TECH_SPEC_v1_1.md` (полное ТЗ);
3. `docs/CLAUDE_ATOMIC_BACKLOG_v1_1.md` (атомарные задачи `ML-001`–`ML-100`);
4. `PROGRESS.md` (проверяемое состояние реализации).

**На этот запуск выполни только `ML-001`.** Не заменяй ID `ML-*` на `F0-*`: в ТЗ есть также крупные фазы, но для детальной работы используется атомарный бэклог.

Требования к работе:
- Перед изменением кода кратко перечисли затрагиваемые файлы, архитектурные границы и план проверок.
- Создай каркас pnpm workspace с `apps/web` и пакетами из архитектурной схемы ТЗ.
- Не добавляй заранее функциональность из следующих `ML-*` задач и не утверждай, что она реализована.
- Запусти применимые проверки; если команды ещё не существуют в `ML-001`, честно укажи `NOT RUN` и причину.
- Проверь критерии приёмки `ML-001` из бэклога.
- Обнови `PROGRESS.md` только после фактической проверки.
- Если разрешены коммиты, создай коммит в отдельной рабочей ветке. Не изменяй `main`, не делай force-push и деплой.
- Отчитайся о выполнении, указав реальные результаты команд, Git SHA (если есть), блокеры и следующую допустимую задачу.

При разрешении работать серией выполняй каждую следующую `ML-*` задачу отдельно, с проверками, фиксацией прогресса и коммитом. При отсутствии такого разрешения остановись после `ML-001`.
