# Модель данных

## Общие контракты

| Поле          | Формат                                          |
| ------------- | ----------------------------------------------- |
| Идентификатор | UUID v4                                         |
| Дата операции | Календарная дата `YYYY-MM-DD`                   |
| Время записи  | Временная метка ISO 8601 в UTC                  |
| Валюта        | Код ISO 4217 из списка, поддерживаемого `Intl`  |
| Сумма         | Строка с целым числом минимальных единиц валюты |

Суммы `opening` и `adjustment` допускают знак. Суммы `income`, `expense` и `transfer` положительны. Валюта операции совпадает с базовой валютой и валютами её счетов.

## Запланированные журналы

- `Account` и `Category` сохраняют идентичность при архивации, чтобы старые записи оставались доступными в истории.
- `Transaction` хранит вид операции, сумму, валюту, счёт и локальную дату. Перевод хранит идентификатор счёта назначения. Доход и расход ссылаются на категорию своего типа.
- `GoalAllocation` хранит знаковую дельту резерва и ссылку на цель.
- `DomainEvent` связывается со своей исходной записью и публикуется после успешного сохранения операции.

Подробные поля и ограничения определены в разделах 22 и 23 ТЗ.
