# Проверка задач и релиза

Для задачи используются критерии её строки в атомарном бэклоге. Результаты команд и причины пропуска записываются в `PROGRESS.md`.

## Проверки рабочей ветки

```sh
pnpm install --frozen-lockfile
pnpm lint
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
```

Для UI проверяется запуск сборки и затронутый сценарий в браузере. Проверки финансовой логики используют точные суммы из раздела 27 ТЗ.

## Критерии первого релиза

Раздел 29 ТЗ содержит полный список условий. Сквозные проверки охватывают запись и повтор команды, сверку отчёта с журналом, перезапуск без сети, резервное копирование и восстановление. На телефоне дополнительно проверяются скрытие сумм, фокус и настройка уменьшенного движения.
