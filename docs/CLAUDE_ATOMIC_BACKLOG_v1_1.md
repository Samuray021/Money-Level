# Money Level — атомарный бэклог для Claude Code

**Версия:** 1.1; сопровождает `MONEY_LEVEL_TECH_SPEC_v1_1.md`. Этот бэклог не заменяет исходное ТЗ.

**Правило:** одна задача `ML-XXX` = один небольшой, проверяемый шаг. Не начинать следующую, пока не выполнены зависимости, тесты и критерий приёмки. В отчётах Claude должен ссылаться на ID задачи и связанные разделы ТЗ.

**Обязательный шаблон работы:** 1) анализ затрагиваемых инвариантов; 2) план файлов; 3) реализация; 4) unit/integration/e2e по контексту; 5) `lint + typecheck + test + build`; 6) отчёт с результатами, diff и следующей задачей. Не лезть в будущие фазы без запроса.
